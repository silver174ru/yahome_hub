# YaHome Hub

Самостоятельная интеграция Home Assistant для Яндекс Умного дома.

Версия **0.3.1**.  Вся логика работает внутри Home Assistant.

## Возможности

- Чтение всех устройств Яндекс-аккаунта через `api.iot.yandex.net/v1.0`.
- Все колонки аккаунта через `quasar.yandex.net/glagol/device_list`.
- Устройства, подключённые к Яндекс Станции, через
  `iot.quasar.yandex.ru/m/v2/user/devices/{id}/configuration` (`child_items`).
- Управление всеми основными типами устройств:
  - свет, лампы, ленты, RGB-подсветка;
  - розетки, выключатели, реле;
  - пылесосы;
  - климат, кондиционеры, термостаты;
  - вентиляторы, очистители, вентиляция;
  - увлажнители и осушители;
  - шторы, жалюзи, ворота, двери, окна;
  - медиаустройства, телевизоры, ресиверы, колонки;
  - датчики температуры, влажности, движения, открытия, протечки, дыма,
    газа, вибрации, кнопки, батареи, освещённости, CO2, PM2.5 и другие;
  - сценарии Яндекс Умного дома;
  - дополнительные range/mode/toggle-возможности как отдельные сущности
    `number`, `select`, `switch`.
- Собственная панель **YaHome Hub** в боковом меню Home Assistant:
  - карточки всех устройств с иконками и комнатами;
  - поиск и фильтр по комнатам;
  - вкладка **«Колонки»** с полноценным медиаплеером: обложка, трек, альбом,
    перемотка, громкость, эквалайзер с пресетами и три визуализации;
  - вкладка **«Яндекс хаб»**: Zigbee-датчики, счётчики и ИК-пульты;
  - управление светом, пылесосом, климатом, вентилятором, шторами,
    медиа и колонками;
  - просмотр всех датчиков;
  - запуск сценариев;
  - кнопка обновления и экспорта базы.
- База данных всех устройств:
  - `Store` Home Assistant: `.storage/yahome_hub.devices`;
  - экспорт JSON: `/config/yahome_hub/devices.json`;
  - экспорт SQLite: `/config/yahome_hub/devices.db`
    (таблицы `devices`, `capabilities`, `properties`, `scenarios`, `rooms`).
- Сервисы:
  - `yahome_hub.send_action` — произвольное действие устройству;
  - `yahome_hub.execute_scenario` — запуск сценария;
  - `yahome_hub.refresh` — принудительное обновление;
  - `yahome_hub.export` — экспорт базы.
- WebSocket API для панели и внешних клиентов:
  - `yahome_hub/devices`;
  - `yahome_hub/action`;
  - `yahome_hub/scenario`;
  - `yahome_hub/refresh`;
  - `yahome_hub/export`.

## Установка

1. Скопируйте `custom_components/yahome_hub` в `/config/custom_components/`.
2. Перезапустите Home Assistant.
3. **Настройки → Устройства и службы → Добавить интеграцию → YaHome Hub**.
4. Вставьте токен Yandex IoT и, при необходимости, cookies.
5. Откройте панель **YaHome Hub** в боковом меню.

Для HACS/Marketplace добавьте репозиторий:

```text
https://github.com/silver174ru/yahome_hub
```

Категория — `Integration`.

## Где взять токен и cookies

Токен:

1. Откройте `https://iot.yandex.ru` или приложение «Дом с Алисой» в браузере.
2. DevTools → Network.
3. Найдите запрос к `api.iot.yandex.net/v1.0/user/info`.
4. Скопируйте значение `Authorization: Bearer ...`.

Cookies (нужны для колонок и дочерних устройств Станции):

1. DevTools → Application → Cookies → `https://yandex.ru`.
2. Скопируйте все cookies в формате `name=value; name2=value2`.
3. Вставьте в поле «Cookies Яндекса».

Подробная инструкция: [COOKIES.md](COOKIES.md).

Токены и cookies — это доступ к аккаунту. Не публикуйте их и не передавайте
третьим лицам.

## Панель

Панель регистрируется автоматически при загрузке интеграции. Она доступна
по адресу:

```text
http://<HA>/yahome-hub
```

Панель требует администратора Home Assistant. Если она не появилась в меню,
проверьте лог Home Assistant и перезапустите его.

## База данных

После каждого обновления каталог сохраняется в `.storage/yahome_hub.devices`.
Полный экспорт можно сделать:

- кнопкой «Экспорт базы» в панели;
- сервисом `yahome_hub.export`;
- WebSocket-командой `yahome_hub/export`.

Файлы:

```text
/config/yahome_hub/devices.json
/config/yahome_hub/devices.db
```

SQLite-база содержит нормализованные таблицы устройств, возможностей,
свойств, сценариев и комнат.

## Безопасность

- В коде нет токенов, cookies, паролей, ID устройств и IP.
- Секреты хранятся только в `config_entries` Home Assistant.
- Запросы идут только на официальные endpoint'ы Яндекса по HTTPS.
- Нет телеметрии, аналитики и сторонних серверов.
- Диагностика редактирует токены и cookies.

## Ограничения

- API Яндекса неофициальный: токен и cookies могут истекать, методы могут
  меняться.
- Без cookies работают устройства аккаунта, но не колонки и не дочерние
  устройства Станции.
- Камеры Яндекса не имеют публичного snapshot-endpoint в IoT API; сущность
  камеры создаётся как карточка устройства без видеопотока.
- Некоторые настройки колонок и вендорские функции доступны только в
  приложении производителя.
- Для голосового управления устройствами Home Assistant через Алису нужен
  отдельный мост `Yandex Smart Home` (HA → Алиса). Этот проект импортирует
  устройства Яндекса в HA, а не заменяет голосовой мост.
